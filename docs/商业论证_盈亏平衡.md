# 商业论证：透明化的盈亏平衡

## 先说方法，再说结论

常见的作品集写法是这样的：

> 假设转化提升 2%，客单价 5 万，月曝光 10 万 → 潜在收益 1 亿。

**这个写法有两个问题。** 第一，2% 从哪来？面试时被追问就答不上来。
第二，更严重的是：一旦这个数字被质疑，旁边那些真实测出来的数字也会跟着被怀疑。
一个编造的数字会污染整份材料的可信度。

这里换一个问法：**不猜收益，而是算"要抵消损失，需要什么条件成立"，
再判断这个条件是否可信。** 未知量从假设变成了结论。

## 场景

展示 IRR 真实年化会让一部分用户放弃分期——**收入减少**。
但更知情的用户投诉更少、首期逾期更少——**成本减少**。

于是问题变成：**投诉率和逾期率要下降多少，才能把转化的损失抵回来？**

## 假设（全部为假设值，非真实业务数据）

| 参数 | 取值 | 来源 |
|---|---|---|
| 月曝光人数 | 100,000 | 假设 |
| 分期转化率 | 12% | 假设 |
| 平均分期本金 | 12,000 | 与语料算例一致 |
| 平均期数 / 每期费率 | 12 期 / 0.6% | 语料 F001 现行费率 |
| 转化相对降幅 | 5% | **待实验测定**，见实验设计文档 |
| 基线投诉率 / 单笔处理成本 | 1.5% / 180 | 假设 |
| 基线首期逾期率 / 单笔损失 | 3.0% / 900 | 假设 |

## 结果

| 项 | 金额（月） |
|---|---|
| 单笔手续费收入 | 864 |
| 流失订单 | 600 笔 |
| **手续费收入损失** | **518,400** |
| 剩余订单的投诉成本基数 | 30,780 |
| 剩余订单的逾期损失基数 | 307,800 |

盈亏平衡所需的降幅：

| 抵消方式 | 需要的相对降幅 |
|---|---|
| 仅靠投诉率下降 | **1684%** |
| 仅靠首期逾期率下降 | **168%** |
| 两者各承担一半 | 842% / 84% |

## 结论

**抵不平，而且差得很远。** 收入损失（518,400）超过投诉成本与逾期损失的**全部基数之和**
（338,580）。即使把投诉和逾期**降到零**，也补不上缺口。

所以正确的结论不是"这个功能不值得做"——**披露是义务，不是可选优化项**，
监管口径（F030）要求以 IRR 明示。正确的结论是：

> **不要用收入口径为合规功能辩护。**
> 应当按合规成本口径立项：明确这是必须做的事，把转化损失作为**已知代价**申报，
> 并在实验中把这个代价测准，而不是假装它不存在或用编造的收益去掩盖它。

这个结论比"预计带来 1 亿收益"难听，但它是能在评审会上站住的那一个。
如果有人拿着"1 亿收益"的 PPT 上会，第一个问题就是"2% 从哪来"，
而这里的答案是"我不知道转化会掉多少，所以我设计了实验去测；
在测出来之前，我先算清楚了它最多能被什么抵消——答案是抵不掉"。

## 敏感性

模型在 `src/business_case.py`，页面上有交互版本。几个值得试的方向：

- **把转化降幅调到 1%**：损失降到 103,680，此时逾期率需下降 34% —— 仍然很高但进入可讨论区间
- **提高单笔逾期损失**：如果实际拨备成本远高于 900，抵消能力会显著改善
- **把展示形式从"劝退数字"改成对比条**：这不改变披露义务，但可能显著降低转化降幅——
  这正是实验设计里第二档决策规则要验证的事
