# 实验设计：在分期入口展示 IRR 口径真实年化

## 为什么是这个实验

这是本组三个项目里唯一一个**商业指标与用户利益直接冲突**的决策，
也是 AI 产品经理绕不开的一类问题。

分期入口目前展示的是"每期手续费 0.6%"。按 F030 的口径，应当同时展示
IRR 口径的实际年化——12 期为 13.03%，3 期为 9.87%（名义仅 1.65%，相差 5.98 倍）。

数字越透明，用户越可能不办分期。**这个实验大概率会让转化率下降。**
所以真正要设计的不是"要不要做"，而是"我们愿意用多少转化率换取什么"。

## 假设与指标

**假设**：展示真实年化会降低分期申请转化率，但会提高完成申请用户的
理解度与后续留存，并降低投诉率。

| 指标类型 | 指标 | 方向 |
|---|---|---|
| 主指标 | 分期申请转化率 | 预期下降 |
| 护栏指标 | 30 日投诉率 | 必须不上升 |
| 护栏指标 | 首期逾期率 | 必须不上升 |
| 反向指标 | 申请后 7 日取消率 | 预期下降（更知情的决策更稳定） |
| 体验指标 | 费率说明页停留时长 | 预期上升 |

## 样本量（真实计算，见 `src/experiment.py`）

基线转化率按 12% 估算：

| 想检出的相对降幅 | 每组样本 | 按日均 8000 曝光 |
|---|---|---|
| 3% | 126,247 | 31.6 天 |
| 5% | 45,049 | 11.3 天 |
| 10% | 11,011 | 2.8 天 |

**这张表本身就是一个产品结论**：如果我们只有两周，就只能检出 5% 以上的降幅。
小于 5% 的下降在统计上看不见——那么产品决策就不该建立在"降了 2%"这种读数上。

## 决策规则（实验开始前写定）

先写规则，再看数据。否则读数会被结论牵着走。

| 情形 | 决策 |
|---|---|
| 转化率降幅 < 5%，护栏指标不恶化 | **全量上线**。合规要求（F030）本就是必须项，代价可接受 |
| 降幅 5%~15%，取消率与投诉率同时下降 | **上线，但改展示形式**：把年化从劝退数字改为对比条，配"提前还款不减免手续费"提示 |
| 降幅 > 15% | **仍然上线**，但升级为专项：说明这不是展示方式问题，而是产品定价本身缺乏竞争力 |
| 任一护栏指标恶化 | 回滚并排查，优先怀疑展示引发误解而非产品问题 |

注意四行的共同点：**没有一行是"不上线"**。F030 是披露义务，不是可选优化项。
实验决定的是**怎么展示**，不是**要不要展示**。这个前提如果不写清楚，
实验就会变成为不合规找数据借口。

## 局限

- 基线转化率 12% 为假设值，没有线上数据支撑
- 护栏指标的观察窗口（30 日）长于主指标，需要分阶段读数
- 未考虑新老用户异质性，正式实验应分层
